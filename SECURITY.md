# Security Policy

## Supported Versions

The following versions of Snapgrove are currently being supported with security updates:

| Version | Supported |
| ------- | --------- |
| 01.07.x | Supported |

## Reporting a Vulnerability

If you discover a security vulnerability, please **DO NOT** open a public issue. Publicly disclosing a vulnerability can put users at risk.

Instead, please report security vulnerabilities directly to the maintainer via GitHub Security Advisories at [https://github.com/SubhamSathua/snapgrove/security/advisories](https://github.com/SubhamSathua/snapgrove/security/advisories) or contact Subham Kumar Sathua via GitHub.

We will acknowledge your report and attempt to address and resolve the issue as quickly as possible.

## Distribution & Malware Disclaimer

The author of this project only provides source code and official release binaries through authorized channels (e.g., this GitHub repository: [https://github.com/SubhamSathua/snapgrove](https://github.com/SubhamSathua/snapgrove)).

- **Official Builds:** Only releases published directly by the original maintainer on GitHub are official "Snapgrove" products.
- **Third-Party Distributions:** We are **not responsible** for versions of this software downloaded from other websites, mirrors, forums, or third-party collections.
- **Modified Versions:** If you download or execute a version that has been modified by someone else, you do so at your own risk.
